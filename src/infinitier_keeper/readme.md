# infinitier_keeper

Cross-engine save-game editor for Infinity Engine games. Inspired by
ShadowKeeper, EEKeeper, and JSEEKeeper — but designed to work against
every IE engine (BG, BG:EE, BG2, BG2:EE, IWD, IWD:EE, IWD2, PST,
PST:EE) from a single binary, sourcing all game-specific knowledge
from the installed game data rather than hard-coded tables.

MVP scope: list the party members in a save game and display their
ability scores (Strength, Strength %, Intelligence, Wisdom,
Dexterity, Constitution, Charisma). Read-only for now; edit support
to follow.
